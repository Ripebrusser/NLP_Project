## Task Type Classification (Critical Distinctions)

| Task Type | Definition | Papers in Our Review | Dataset Labels |
|-----------|------------|---------------------|----------------|
| **Spam detection** | Unsolicited bulk messaging, mostly promotional | P01, P07, P10 | ham / spam |
| **Smishing detection** | SMS phishing — deceptive messages aiming at credentials or money via SMS | P02, P03, P04, P05, P09, Mahmood & Hameed (2023) | ham / smishing (sometimes spam relabeled as smishing) |
| **Phishing detection (general)** | Deceptive messages aiming at credentials/money (may include email, SMS, other channels) | P06, P08 (multilingual phishing) | ham / phishing (varies) |
| **Malware detection** | Detection of malicious software links or attachments | P02 (APK download module) | malware / benign (URL/APK level) |
| **Offensive language / hate speech** | Abusive, hateful, or offensive text content | P12 (DravidianCodeMix) | sentiment / offensive language (NOT cybersecurity) |

**CRITICAL WARNING:** These labels are NOT interchangeable. A spam detector is not a phishing detector. A smishing detector is not an offensive-language detector. Using DravidianCodeMix (sentiment/offensive labels) as a phishing corpus would be incorrect.
